# Final checkpoint downloads and restoration

This directory holds 14 final-checkpoint ZIPs prepared for GitHub Releases. It does not contain datasets. `.gitignore` excludes this directory from normal Git commits.

Each ZIP contains checkpoint paths under `checkpoints/`, preserving the recorded experiment-relative layout. Six byte-identical aliases are stored once; use the restore script to materialize every manifest path rather than relying on manual unzip alone.

After downloading the ZIPs and SHA256SUMS from the matching GitHub Release into `release_assets/`:

```bash
cd release_assets
sha256sum -c SHA256SUMS
cd ..
python scripts/restore_checkpoints.py
python scripts/verify_checkpoints.py
```

The restore script reads local archives, verifies hashes, rejects differing existing files, and restores ordinary files. It does not download data or weights. Use `--group` to restore one model group; see `--help` for exact options. To verify a subset, retain the full manifest and consult the verifier's supported modes; do not relabel an incomplete local copy as a full release verification.

The manifest lists 534 checkpoint paths. There are 528 unique payloads stored in ZIPs and 6 aliases; the complete restored tree contains all 534 ordinary files. DLinear-only exports omit the unrelated NLinear model and optimizer/RNG state, with exact parameter and fixed-input parity recorded in `manifests/CHECKPOINT_MIGRATION_AUDIT.json`.

Publish the ZIPs plus `SHA256SUMS` as assets of the same tagged GitHub release as the source code. The normal source-code ZIP generated by GitHub does not include these release assets.

To download using GitHub CLI after publication, replace the repository name and tag:

```bash
mkdir -p release_assets
gh release download paper-v1 --repo YOUR_ACCOUNT/SCPRC --pattern "*.zip" --pattern "SHA256SUMS" --dir release_assets
```

You can also download attachments in the browser. A normal source-code ZIP contains no model weights or datasets.
